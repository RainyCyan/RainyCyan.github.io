1. 背景问题

KVCache 存储侧面临的痛点问题主要是：
- 空间瓶颈，GPU SRAM/DRAM、本机CPU DRAM、SSD；
- IO 链路的带宽瓶颈。

通常会想对数据进行压缩，以解决上面的问题：
无损压缩
有损压缩（低比特量化）
- 模式匹配：LZ4/LZ77；
- 熵编码：Huffman coder， ANS 等；
- ZSTD；
- 简单的精度截断：将高精度的数据（如FP32，FP16）scale到低精度的数据表示（int8，int4）。
- 用低维向量表示高维向量，如PQ （Product Quantization）
- 保持向量的维度不变，每个维度用更少的bit表示，如RabitQ，TurboQuant。
- 优点：对精度无任何损失；
- 缺点：可压缩空间受限于香农第一定理。对于任意的数据源和给定的信息熵（entropy），存在一种编码方式，使得编码后的数据的平均长度接近于数据源的熵值。
- 优点：可压缩空间比较大；
- 缺点：保持数据精度是一个很大的挑战




2. KVCache 量化面临的挑战

KVCache 场景下的量化技术需要同时满足以下三个条件（论文中提到，目前还没有一种量化方法能同时满足这三个条件）：
- 支持在线量化（Data-oblivious）
  - 在对数据进行压缩的时候不用依赖数据集的相关信息，对于任何时候存入系统的Token都能对其进行独立的压缩，不需要关注数据的上下文信息。
- 量化本质是有损压缩，目标是尽可能降低失真率，使其在效果上接近无损。
  - 量化本质上是有损压缩
- 能够适配GPU加速压缩解压缩
  - 充分利用GPU并行计算能力，减少压缩带来的计算开销
  - 避免CPU与GPU之间的数据拷贝


3. 解决方案: TurboQuant

本方案的两个子目标：
- 通过 MSE Optimized TurboQuant 最小化均方误差（MSE），保证量化后数据的还原误差足够小；
[图片]
- 其次，通过 Inner Product TurboQuant 提供对内积的无偏估计，确保向量间的几何结构（以内积衡量）得以保持，这对保证召回率十分重要。
[图片]


算法概览
- 前提是所有向量都进行了归一化处理[-1,1]，那么就可以把每个向量看作是d维超球面上的一个点；
- $$TurboQuant_{mse}$$算法原理 
  - Step 1. 先把数据所携带的信息在不同的维度之间打散，确保每个维度分到的信息量是相同的；
    - 先初始化一个随机的正交矩阵 $$\Pi
$$，将向量与 $$\Pi$$相乘会把向量的数据分布在d维球面上打散，此时可理解为数据在点在d维超球面上是均匀分布的；
  - Step 2. 得出每个维度的数据分布；
    -  根据超球面几何的定理，如果点在球面上是均匀分布，对于某个维度而言，坐标等于x的概率就完全等价于，在高度为 $$x
$$ 的地方切一刀，切出来的那个面的边缘面积有多大，经过高维几何推导可以进一步算出这个面积就是统计学中的Beta分布；
  - Step 3. 对每个维度的数据进行量化；
    - 在已知数据服从Beta分布的情况下，也已知位宽为 $$b$$，可以表示 $$2^b$$个数据，我们应该决定把这些数据的量化中心定在哪里？求解这个问题用到了Lloyd-Max算法，可以求出数学绝对最优的中心点位置。
      - 这一步相当于把[-1,1]这个区间切分成了 $$2^b$$个子区间，每个区间都有一个中心点；量化时，每个维度的值会和自己对应维度的所有中心点做比较，跟哪个值最接近就被划分到那个区域，量化后的数据用子区域的索引号表示（0～ $$2^{b-1}$$）
- 通过以上方法能保证量化后的数据与原始数据的差异最小；但是这种计算方法可能会导致计算出来的相似度会按比例缩水，在实际的向量检索/召回算分过程中因为微小的误差，导致排序的灾难；
  - 为此， $$TurboQuant_{prod}$$基于Johnson-Lindenstrauss 引理和无偏估计，把丢掉的残差补回来；该方法需要占用 1 bit的位宽
    - Step 1.  具体而言，首先计算原始向量减去解压后向量的值，记为残差 $$r$$
    - Step 2. 初始化一个高斯随机向量 $$S$$，并于 $$r$$相乘；
    - Step 3. 对于每个维度，只记录相乘后数据的正负号（1 bit）；
    - Step 4. 基于 Johnson-Lindenstrauss 引理求准确残差
      - 给定一个查询向量 $$y$$,使其与 $$S$$相乘；再用其结果与 $$<S, r>$$的符号相乘；JL 引理在数学上保证了：利用高斯随机矩阵将高纬向量映射到低维空间后，向量之间原本的相对距离和内积关系能够得到极高精度的保留。
    - Step 5.（大数定律）最后一步就是使用上百个随机向量 $$S$$做上面的操作，然后把所有Step 4的结果相加，得出的值就无限接近 $$y$$与 $$r$$的真实内积，将这个值与 $$TurboQuant_{mse}$$相加，就可以得到准确的排序了。


3.1 MSE Optimized TurboQuant  压缩流程
该方法旨在最小化原始向量与量化后还原向量之间的均方误差（MSE）。其核心思想是将高维向量的量化问题分解为一系列独立的标量量化问题。详细流程如下（见论文 Algorithm 1）：

- 0. 全局初始化 （只需两个参数：目标位宽b 和 向量维度 d 就可以生成一个全局码表）
  - 先生成一个随机的旋转矩阵  $$\Pi \in \mathbb{R}^{d \times d}$$；
  - 生成码表：求解连续的一维 k-means 优化问题，提前算好 $$2^b$$ 个最优的标量量化中心点 $$c_1, c_2, ..., c_{2^b}$$ ;
  - 上面两步通过beta分布相互合作，所以需要下面的先对原始数据进行随机旋转使数据遵循beta分布；生成码表的过程就是针对beta分布求解k-means问题；
- 1. 随机旋转 (Random Rotation)：
  - 当一个新的向量 $$x$$ 输入时，首先用旋转矩阵乘以它，得到 $$y = \Pi \cdot x$$。
    - 这一步是关键，它使得无论原始输入 $$x$$ 是什么，旋转后的向量  $$y$$ 在单位球面上均匀分布。其每个坐标 $$y_j$$ 都服从一个 Beta 分布。在这个分布下，不同坐标的概率已知且相互独立。当维度很高（即d很大）的时候，Beta分布会收敛成正态分布。
- 2. 独立标量量化 (Independent Scalar Quantization)：
  - 对于旋转后向量  $$y$$ 的每一个坐标  $$y_j$$，独立地寻找预计算好的码本 C = {c_1, ..., c_{2^b}} 中最接近的码字 $$c_k$$ 。
  - 这个码本 C 是针对 Beta 分布通过求解一维 k-means 问题（使用 Lloyd-Max 算法）预先计算出的最优标量量化器，b 是目标 bit 位宽。
  - 记录下每个坐标 y_j 对应的最近码字的索引 idx_j。最终输出一个由 $$d$$ 个 $$b
$$ 位整数组成的索引向量 idx
- 3. 反量化流程：
  - 还原码字：根据索引 idx，从码本 C 中取出对应的码字，构建出向量 ỹ。
  - 逆向旋转：对 ỹ 右乘旋转矩阵的转置 Π^T，得到最终的还原向量 ˜x = Π^T · ỹ。


3.2 Inner Product TurboQuant  压缩流程
MSE Optimized TurboQuant 虽然能有效降低还原误差，但在用于内积估计时会产生偏差（bias）。为了解决这个问题，论文提出了一种专门为内积估计优化的两阶段算法 Inner Product TurboQuant，它能实现对内积的无偏估计。流程如下（见论文 Algorithm 2）：
- 1. 第一阶段：(b-1)-bit MSE 量化：
  - 假设总比特预算为 b，首先使用一个 b-1 比特的 MSE Optimized TurboQuant 对输入向量 x 进行量化和反量化，得到 ˜x_mse。
  - 计算出残差向量 r = x - ˜x_mse。由于第一阶段的量化已将大部分信息编码，所以残差向量 r 的 L2 范数 ||r|| 会很小。
- 2. 第二阶段：1-bit QJL 量化残差：
  - 对残差向量 r 应用 1-bit 的 QJL (Quantized Johnson-Lindenstrauss) 变换进行量化。
  - QJL 是一种能对内积提供无偏估计的 1-bit 量化技术。它通过一个随机投影矩阵 S 将残差 r 投影，然后取其符号，得到量化结果 qjl = sign(S · r)。
  - QJL 的反量化过程为 ˜x_qjl = (sqrt(π/2d) * ||r||) * S^T · qjl。注意这里需要用到残差的范数 ||r||，因此它也需要作为元数据被存储。
- 3. 最终结果：
  - 最终的还原向量是两个阶段结果的和：˜x = ˜x_mse + ˜x_qjl。
  - 这个组合结果在数学上被证明对于任意查询向量 y，其内积估计 E[<y, ˜x>] 等于原始内积 <y, x>，即实现了无偏估计。
  - 量化产出包括第一阶段的码字索引 idx、第二阶段的 QJL 量化结果 qjl，以及残差的范数 ||r||。

4. 实验结果


4.1 无偏性验证

指标是无偏估计，意思是虽然单次计算可能有误差，但在宏观平均意义上，估算值完全等于真实值。

[图片]


证实无偏性：实验证实了 $$\text{TURBOQUANT}_{\text{prod}}$$ 确实是无偏的，其内部内积计算的误差分布完美契合了他们在理论推导中给出的数学下界。
揭示 MSE 偏差：证实了纯 $$\text{TURBOQUANT}_{\text{mse}}$$ 在低位宽下计算内积确实存在明显偏差，并且这个偏差会随着两个向量的平均内积增大而变得更严重。不过随着位宽的增加，这种偏差会逐渐缩小直至收敛 。

5. GravityDB 能否用这项技术

对于一个业务而言，如果他们存入的向量规格是固定的，即给定向量的维度和数据类型（比如BF16）；GDB就能够对业务存下的数据解析然后逐个压缩。 
- 元数据开销？
  - 由于向量的维度d是固定的，位宽 b也是固定的，因此量化后的数据不会有很多元数据开销
- 其他依赖？
  - 需要对每个向量进行正则化，使其模长为1。
- 可能的坑
  - 离群值。有的维度数据取值范围可能会很大，如果对所有的维度都采用相同的位宽，也会损失精度。
- 选择 $$TURBOQUANT_{mse}$$ or $$TURBOQUANT_{prod}$$
  - 距离业务越远，尽量使用 $$TURBOQUANT_{mse}$$，这样能最大化保证数据携带的原始信息，使上层业务无感
