dfs 与图#

dfs的理论思想就是先沿着一个方向探索，到头或碰壁后返回上一个节点探索其他方向，更换方向的过程需要撤销原先的探索（回溯） 因此代码框架实际就是回溯的结构

void dfs(参数) {
    if (终止条件) {
        存放结果;
        return;
    }

    for (选择：本节点所连接的其他节点) {
        处理节点;
        dfs(图，选择的节点); // 递归
        回溯，撤销处理结果
    }
}
